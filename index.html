Biography

I am a third year Ph.D. student in Computer Science & Information Systems at the College of Engineering, Design and Computing, University of Colorado Denver (CU Denver), advised by Prof. Zhengxiong Li.

My research aims to build robots that manipulate the physical world reliably. I work on dexterous manipulation, particularly visuo-tactile foundation models and vision-language-action (VLA) models. Such models depend on large-scale interaction data, so I also build the systems that produce it, including VR-based teleoperation.

2026 — Present

Cortex

An open-source autonomous agent system for long-running research projects. Given a mission and a success criterion, Cortex plans the work, dispatches pipelines of agents to execute it, keeps a structured log of progress in the repository, and reviews itself before each commit — across days or weeks of unattended work.

  • Mission-driven task system: decomposes a goal into tracked tasks with priorities, dependencies, and verifiable done-conditions, working through them autonomously and escalating only when blocked
  • Multi-agent thread pipelines: long jobs run as a relay of focused agents, each starting with clean context and a narrow scope, with handoffs carrying only what the next stage needs
  • Structured project log: mission, roadmap, status, experiments, knowledge, patterns, and decisions persist as plain files in the repository, so a fresh agent can resume where the last one stopped
  • Server-client architecture: a Node.js orchestration server drives remote agent instances over WebSocket, with Slack integration, scheduling, and desktop and Android clients built on Tauri
TypeScript Node.js Claude API WebSocket Tauri Python

AIStatus

A real-time AI model status monitoring platform with intelligent routing SDK and local gateway proxy, helping developers and AI agents navigate the rapidly evolving AI infrastructure landscape.

  • Platform (aistatus.cc): Real-time status dashboard for 12+ AI providers, model pricing & ranking comparison, MCP server monitoring, and vector database status tracking
  • Backend: Serverless API built with Hono on Cloudflare Workers with D1 database, featuring usage leaderboard, telemetry ingestion, and zero-ops deployment
  • SDK (Python & TypeScript): Zero-config intelligent routing (route("Hello", model="claude-sonnet-4-6")), automatic provider discovery from environment variables, tier-based model fallback, and cost calculation
  • Gateway: Local transparent HTTP proxy with API key rotation, provider fallback chains, SSE streaming support, model-level health tracking, and per-request usage analytics
